### Halo, saya Ahmad Ngiliyun

Dosen tetap dan Sekretaris Program Studi Informatika di **Universitas Insan Mahardika**, Cirebon, sekaligus co-founder **AWATARA Research and Education Solution**. Saya mengajar, meneliti machine learning, dan mengubah ide di ruang kelas menjadi aplikasi yang benar-benar dipakai.

Saya percaya cara terbaik mengajar teknologi adalah dengan ikut membangunnya: materi kuliah lahir dari proyek nyata, dan proyek nyata menjadi bahan riset.
